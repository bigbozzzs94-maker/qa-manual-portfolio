# Test Plan

## 1. Project

**Project:** BookCart  
**Platform:** Web Application + REST API  
**Version:** 1.0

---

## 2. Testing Objective

The objective of testing is to verify the main functionality of the BookCart application and ensure that critical user flows work correctly.

---

## 3. Scope

### In Scope

- User Registration
- User Authentication
- User Profile
- Product Catalog
- Product Search
- Shopping Cart
- Checkout
- Order History
- REST API

### Out of Scope

- Performance Testing
- Security Testing
- Load Testing

---

## 4. Testing Types

- Functional Testing
- UI Testing
- API Testing
- Regression Testing
- Smoke Testing
- Cross-browser Testing

---

## 5. Test Environment

| Environment | Details |
|---|---|
| Application | Web Application |
| Browser | Google Chrome |
| API Tool | Postman |
| API Documentation | Swagger |
| Database | SQL Server |

---

## 6. Entry Criteria

- Application is available for testing
- Test environment is configured
- Requirements are available
- Test data is prepared

---

## 7. Exit Criteria

- Critical test cases are executed
- Critical defects are fixed
- Regression testing is completed
- Test results are documented

---

## 8. Risks

- Unstable test environment
- Incomplete requirements
- Limited test data
- Backend API availability issues
