# QA Manual Portfolio

Welcome to my QA portfolio.

This repository contains examples of QA documentation and testing artifacts created for the **BookCart — E-commerce Web Application** project.

The portfolio demonstrates my practical skills in manual testing, test documentation, API testing, SQL, bug reporting, and test design.

---

## 📌 Project Overview

**Project:** BookCart — E-commerce Web Application  
**Platform:** Web (Desktop)  
**Testing Type:** Manual Testing  
**Main Areas:**

- Registration
- Authentication
- Product Catalog
- Product Search
- Shopping Cart
- Checkout
- Order Management
- API Testing
